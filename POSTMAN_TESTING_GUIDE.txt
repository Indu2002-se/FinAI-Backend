FinAI Backend - Postman Testing Guide
=====================================

SETUP:
------
1. Start MySQL: scripts\start-mysql.bat
2. Run Application: gradlew.bat bootRun
3. Wait for "Started BackendApplication" message
4. Base URL: http://localhost:8080

=====================================
TEST 1: REGISTER NEW USER

URL: http://localhost:8080/api/v1/auth/register

Content-Type: application/json

  "lastName": "Doe",
  "email": "john.doe@example.com",

  "phoneNumber": "1234567890"

=====================================
ERROR SCENARIOS TO TEST:
=====================================

1. REGISTER WITH EXISTING EMAIL:
   Body: Same email as registered user
   Expected: 400 Bad Request
   {
     "timestamp": "...",
     "status": 400,
     "error": "Bad Request",
     "message": "Email already registered",
     "path": "/api/v1/auth/register"
   }

2. LOGIN WITH WRONG PASSWORD:
   Body: Correct email, wrong password
   Expected: 401 Unauthorized
   {
     "timestamp": "...",
     "status": 401,
     "error": "Unauthorized",
     "message": "Invalid email or password",
     "path": "/api/v1/auth/login"
   }

3. REGISTER WITH WEAK PASSWORD:
   Body: password = "123"
   Expected: 400 Bad Request
   {
     "timestamp": "...",
     "status": 400,
     "error": "Bad Request",
     "message": "Validation failed",
     "path": "/api/v1/auth/register",
     "validationErrors": {
       "password": "Password must be at least 8 characters long"
     }
   }

4. REGISTER WITH INVALID EMAIL:
   Body: email = "notanemail"
   Expected: 400 Bad Request
   {
     "validationErrors": {
       "email": "Invalid email format"
     }
   }

5. ACCESS PROTECTED ENDPOINT WITHOUT TOKEN:
   GET /api/v1/auth/me (no Authorization header)
   Expected: 401 Unauthorized

=====================================
POSTMAN TIPS:
=====================================

1. Create a Collection called "FinAI API"

2. Create an Environment:
   - Name: FinAI Dev
   - Variables:
     * baseUrl = http://localhost:8080
     * token = (will be set automatically)

3. Use Variables in Requests:
   - URL: {{baseUrl}}/api/v1/auth/register
   - Authorization: Bearer {{token}}

4. Auto-save token after login:
   In Tests tab of Login request, add:
   ```javascript
   var jsonData = pm.response.json();
   pm.environment.set("token", jsonData.data.token);
   ```

5. Pre-request script for Authorization:
   In Authorization tab, select "Bearer Token"
   Token: {{token}}

=====================================
SWAGGER UI ALTERNATIVE:
=====================================

You can also test via Swagger UI:
URL: http://localhost:8080/swagger-ui.html

1. Open Swagger UI
2. Find "Authentication" section
3. Click on endpoint to expand
4. Click "Try it out"
5. Fill in request body
6. Click "Execute"
7. For /me endpoint:
   - First click "Authorize" button (top right)
   - Enter: Bearer <your-token>
   - Click "Authorize"
   - Then test /me endpoint

- user_roles

=====================================
COMMON ISSUES:
=====================================

1. Connection refused:
   - Make sure MySQL is running
   - Check: docker ps

2. Application not starting:
   - Check: gradlew.bat bootRun
   - Look for errors in console

3. 401 Unauthorized on /me:
   - Check token format: "Bearer <token>"
   - Token might be expired (valid for 24 hours)
   - Login again to get new token

4. Validation errors:
   - Check request body format
   - Ensure all required fields are present
   - Check password meets requirements
