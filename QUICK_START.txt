FinAI Backend - Quick Start Guide
=================================

PREREQUISITES:
- Java 21
- Docker Desktop (for MySQL)
- Gradle 8.5+ (included via wrapper)

SETUP STEPS:

1. Start MySQL Container:
   Windows: scripts\start-mysql.bat
   Linux/Mac: ./scripts/start-mysql.sh

2. Verify MySQL is running:
   docker ps
   (You should see finai-mysql container running)

3. Run the application:
   Windows: gradlew.bat bootRun
   Linux/Mac: ./gradlew bootRun

4. Verify application is running:
   Open: http://localhost:8080/swagger-ui.html
   Test: http://localhost:8080/api/health

5. Stop MySQL when done:
   Windows: scripts\stop-mysql.bat
   Linux/Mac: ./scripts/stop-mysql.sh

CONFIGURATION:
- Development: application-dev.properties
- Production: application-prod.properties
- Testing: application-test.properties (uses H2 in-memory DB)

DATABASE CONNECTION:
- Host: localhost:3306
- Database: finai_dev
- Username: finai_user
- Password: finai_password

API DOCUMENTATION:
- Swagger UI: http://localhost:8080/swagger-ui.html
- API Docs: http://localhost:8080/api-docs

TESTING:
Run tests: gradlew test
Build: gradlew build

HEALTH CHECK:
GET http://localhost:8080/api/health
GET http://localhost:8080/api/health/ping

TROUBLESHOOTING:
- If MySQL fails to start, check if port 3306 is available
- If build fails, run: gradlew clean build
- Check logs in: logs/finai-backend.log
